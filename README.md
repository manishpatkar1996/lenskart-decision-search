# aggregate-40204

Interactive Lenskart decision-search case-study prototype.

The prototype demonstrates three applications of one intent-aware search system:

- guided style and fit discovery;
- safe exact contact-lens reordering; and
- assisted shopping for a parent.

## Run locally

```bash
npm install
npm run dev
```

## GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the static prototype after every push to `main`.

```bash
npm run build:pages
```

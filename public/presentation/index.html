B, voice, AR, profiles and stores already exist. The missing layer is a shared, typed decision state.

03 · Query understanding · QU

Parse into state, not prose.

Rules extract SKU, ₹, power and services. A language model may map Hinglish into the schema. It never invents numeric constraints.

Unknown does not mean false. It means preserve optionality.

05 · Retrieve + rank · RK

01 Understand02 Route + gate03 Rank eligible04 Compose

Rank is downstream of correctness.

Exact entity path first. Otherwise score the eligible set using lexical match, attributes, soft profile, quality and a capped business term.

No vector database or LambdaMART until ranking—not understanding or routing—is the measured miss.
